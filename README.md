# Семантическое преобразование HTML-таблиц с помощью модели

Прототип получает HTML и экспортирует CSV с одной строкой заголовков и JSON с исходными координатами. Языковая модель определяет, где значения, какие заголовки к ним относятся и где указаны единицы. Python читает HTML, подставляет исходные тексты по адресам и проверяет ссылки. Одинаковые числа в разных ячейках сохраняются как разные записи.

В [SMART](https://aclanthology.org/2026.findings-acl.1474/) модель раскрывает смысл многоуровневых заголовков перед ответом на вопрос. В [ASTRA](https://aclanthology.org/2026.acl-long.1090/) модель восстанавливает иерархию, а в режиме SRE может вернуть ссылки на ячейки, по которым код подставляет исходные тексты. Мы объединили эти две идеи в собственной предобработке, выход которой можно передать Text2SQL или Text2Python.

## Запуск

Распакуй архив и открой его папку в терминале. Достаточно Python 3.11, пакеты ставить не нужно. Первый запуск можно сделать без ключа:

```bash
python3.11 src/semantic_flatten.py examples/hitab_100.html \
  --schema examples/hitab_100_chatgpt.json --output demo/hitab_100
```

Схема `examples/hitab_100_chatgpt.json` создана в этом чате по входным ячейкам. Команда проверяет схему и формирует результат на её основе. Для нового вызова модели на том же HTML запусти:

```bash
python3.11 src/semantic_flatten.py examples/hitab_100.html --output demo/hitab_100_live
```

Скрипт предложит ввести действующий ключ OpenRouter скрытым вводом. Можно также задать переменную окружения `OPENROUTER_API_KEY`. По умолчанию используется `deepseek/deepseek-chat-v3-0324`. Передай `--model` с ID другой модели OpenRouter, если нужно. Для API модель должна поддерживать JSON-ответы. Вызов посылает содержимое таблицы в выбранную модель и может расходовать кредиты OpenRouter.

CSV можно открыть в Numbers, а в JSON доступны полные списки заголовков, координаты, исключённые ячейки с причиной и метаданные запуска. В режиме API туда также попадают модель, провайдер и статистика токенов, если их вернул сервис. Координата `R7C2` означает строку 7, столбец 2 развёрнутой сетки HTML, считая с единицы.
